# Q4 variance task

Create `analysis.csv` and `cfo-brief.md` from `actuals.csv` and `budget.csv`.

- Preserve both source files byte for byte.
- Variance is actual minus budget.
- A variance is material when its absolute value is at least 1,500.
- `analysis.csv` must contain account, actual, budget, variance, and material.
- `cfo-brief.md` must state total operating profit for actual and budget, then explain every material variance without inventing a cause.
