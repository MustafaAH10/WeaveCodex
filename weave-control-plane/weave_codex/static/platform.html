PLATFORM NOTE · AUGUST 2026

Codex supplies the capable loop.
Weave supplies the contract.

Codex can inspect, reason, call tools, recover, and keep going. Weave does not replace that loop. It lets a person decide which outcomes must happen in which order, where work pauses, and what counts as done.

THE CENTRAL DISTINCTION

A workflow phase is a promise to achieve a goal. It is not one tool call.

A single Codex turn may read forty files, run twenty commands, revise its plan, and retry a test. Weave wraps that complete turn with an intent, a boundary, and a receipt. This keeps the runtime adaptive while making the larger process legible.

WHO OWNS WHAT

A clean seam, not a second agent

Codex

Owns the work inside a turn

  • Maintain model-visible context
  • Select and execute tools
  • Stream typed events and progress
  • Apply sandbox and approval policy
  • Recover, retry, steer, or interrupt
Weave

Owns the process between turns

  • Pair a plain-language goal with an editable starting contract
  • Sequence goal-level work and verification
  • Pause at explicit human decision points
  • Scope memory and integrations by phase
  • Save a reusable, versioned workflow receipt

DOES NOT DO

Weave does not replace Codex’s planner, expose hidden reasoning, or schedule every shell command as a canvas block.
