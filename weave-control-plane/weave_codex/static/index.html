THE DIFFERENCE

Weave does not replace Codex

It makes the outer workflow explicit, reusable, and reviewable.

01

Handcraft the workflow

Split a broad task into goal-level phases such as investigate, propose, implement, and verify. Each work phase remains a full Codex agent loop.

02

Pause at real decision points

Put a human checkpoint between phases. Continue or stop without pretending every internal tool call needs your approval.

03

Choose prior experience

Run clean, use native Codex memory, or select exact prior thread excerpts. The receipt records what was selected.

04

See what actually happened

Inspect the authored phases and the native Codex activity inside them. Projections from older threads are clearly marked as derived.

A quick safety checklist.

            
  • Your workspace path points to the intended repository.
  • Read-only or workspace-write sandbox matches the task.
  • Protected actions ask, auto-review, or remain denied as you chose.
  • Selected-memory receipts contain the exact thread IDs used.
