DOCS
Weave around Codex.
Codex still plans, reads, edits, and uses tools. Weave adds a small, human-owned graph that decides when a new turn starts, what it must accomplish, what evidence must pass, and where you can redirect it.

        
1
Your canvas
Nodes and arrows become a validated workflow.
→
2
Weave runtime
Runs each node in dependency order and records the handoff.
→
3
Codex app-server
Uses your ChatGPT sign-in, filesystem, tools, skills, and MCP connections.

        
What a node controls
  • The goal for this turn
  • Broad or focused scope
  • An exact command and expected exit code
  • A calibration question or review rule
What stays native to Codex
  • Its internal reasoning and tool loop
  • Filesystem reads and edits
  • Sandbox and protected-action policy
  • Skills, MCP servers, and connected apps
What gets recorded
  • Node order and outcome
  • Your calibration feedback
  • Observed exact-check status
  • Inputs, context, and visible output

        
SETUP
Start locally
1git clone https://github.com/MustafaAH10/WeaveCodex.git
2npm install -g @openai/codex && codex login
3cd WeaveCodex/weave-control-plane && uv sync
4uv run python -m weave_codex.server --codex-bin "$(command -v codex)" --host 127.0.0.1 --port 8790
