Codex is the agent loop.
Weave makes its outer workflow editable.

Codex still decides how to inspect, reason, edit, run tools, and recover. Weave sits one level above it: people author complete goals, place decision points between them, and retain evidence about what actually ran.

ONE CURATED SYSTEM ARCHITECTURE

Follow a task from the client to the result

Codex only. A client sends a task through app-server; Codex owns the adaptive context → model → tools loop.

THE PRODUCT BOUNDARY

We change four things—and leave the agent alone

01

Workflow

Turn one large prompt into named, reusable goals such as inspect, approve, implement, and verify.

02

Human control

Pause between complete Codex turns. Native approvals still govern risky actions inside a turn.

03

Experience

Choose no prior work, all eligible work, or exact prior threads—with the selection recorded.

04

Evidence

Bind the authored goals and human decisions to observed Codex turns in a local run receipt.

Codex still owns

Reasoning, context construction, tool choice, retries, shell and file operations, MCP/Skills/AGENTS.md, sandboxing, and action approvals.

Weave owns

The outer phase program, between-phase checkpoints, selected-memory declaration, verification contract, and intent-to-trace receipt.

TECHNICAL NOTES

Where Codex integrations enter

Why a phase is not a tool call

A Work phase compiles to one Codex turn. Inside that turn, Codex can read, edit, test, call MCP tools, recover, and resample as often as needed. The canvas describes the goal boundary, not guessed tactics.

AGENTS.md chain, Skills, MCP, and Apps

AGENTS.md and Skills shape instructions and procedures. MCP and Apps expand the callable tool surface. Weave inventories and selects these Codex-owned integrations; it does not copy their credentials.

What the visualization can prove

Exact Weave phases come from the manifest and receipt. Native Codex activity groups are a deterministic projection of persisted items—not hidden reasoning or a reconstructed private plan.

THREE STEPS

Start from a fresh computer

  1. 1

    Install Codex and sign in

    ChatGPT sign-in is the recommended route when you want usage to follow an eligible ChatGPT plan.

    npm install -g @openai/codex
codex login
  2. 2

    Clone and start WeaveCodex

    The server binds to your own machine and delegates agent execution and authentication to Codex.

    git clone https://github.com/MustafaAH10/WeaveCodex.git
cd WeaveCodex/weave-control-plane
uv run python -m weave_codex.server \
  --codex-bin "$(command -v codex)" \
  --host 127.0.0.1 --port 8790
  3. 3

    Open the local app

    Keep the terminal open while you use the site. Your repository path, sandbox, approvals, integrations, and account remain controlled by the local Codex runtime.
