# Customer update runbook

During an active incident, publish an update every 30 minutes from the latest published update.
State observed impact, current investigation status, and the next update time. Label inference as
inference. If root cause is not confirmed, say so plainly. Never promise recovery time without a
confirmed estimate from the incident record.

Use source anchors in internal briefs: `[incident_log.json#INC-42]`,
`[status_history.md#09-30Z]`, and `[runbook.md#customer-update-runbook]`.
